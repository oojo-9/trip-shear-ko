# 트립노트

친구들과 함께 쓰는 여행 일정 · 가계부 · 환율 · 사진첩 웹앱입니다. 설치 없이 브라우저에서 열고, 폰에서는 "홈 화면에 추가"로 앱처럼 씁니다.

- **들어가는 법**: 배포한 주소를 열고 비밀번호를 한 번 입력 (기기마다 처음 한 번)
- **내 사이트 주소·프로젝트 이름**: `개인메모.md`에 따로 적어 둡니다 (Git에 올리지 않음)
- **마지막 정리**: 2026-11-12

이 저장소를 받아 직접 쓰려면 `config.example.js`를 `config.js`로 복사해 값을 채우세요. `config.js` 없이도 지도 없는 기기 저장 모드로 동작합니다.

## 1. 기능

| 탭 | 할 수 있는 것 |
|---|---|
| 🗺️ 일정 | 날짜별로 장소 추가, 구글 지도에 번호 핀 표시, 순서 변경. 장소 검색 시 주소·영업시간 자동 입력. 구간마다 대중교통 / 택시·차량 / 도보 시간 표시 |
| 🧾 가계부 | 직접 입력 또는 영수증 사진 스캔. 현지 금액을 원화로 자동 환산, 분류별 합계, 멤버별 정산 |
| 💱 환율 | 현지 금액 → 원화, 카드 결제 시 수수료 포함 예상 금액, 원화 예산 → 현지 금액, 빠른 환산표 |
| 📷 사진 | 날짜별 사진 저장, 한 줄 메모, 슬라이드쇼, 여행북(PDF) 만들기 |
| ⚙️ 설정 | 여행 이름·날짜·통화·멤버 수정, 초대 링크 복사, Gemini 키 입력, 연결 상태 확인 |

## 2. 친구와 공유하기

1. 공유할 여행을 열고 오른쪽 위 🔗 버튼(또는 설정 탭의 "초대 링크 복사")을 누릅니다.
2. 복사된 링크(`…/#t=영문숫자20자리`)를 친구에게 개인 메시지로 보냅니다. 비밀번호도 따로 알려줍니다.
3. 친구가 링크를 열고 비밀번호를 넣으면 같은 여행이 열리고, 일정·가계부·사진을 함께 추가·수정·삭제할 수 있습니다.

- 앱 주소만 보내면 첫 화면만 나오고 내 여행은 보이지 않습니다. 반드시 초대 링크를 보내세요.
- 초대 링크와 비밀번호를 아는 사람은 누구나 그 여행을 수정할 수 있습니다. 공개된 곳에 올리지 마세요.
- **홈 화면에 추가한 앱에서 여행이 안 보일 때**: 홈 화면 앱은 브라우저와 저장 공간이 달라 "내 여행" 목록이 비어 있습니다. 첫 화면의 **기존 여행 불러오기**에 초대 링크를 붙여넣으면 됩니다. 여행 데이터는 서버에 그대로 있습니다.

## 3. 앱을 고친 뒤 다시 올리는 법

1. 수정은 이 폴더(`여행`)의 파일에서 합니다.
2. 수정된 파일을 `배포용` 폴더에 복사합니다. (`index.html`, `config.js`, `manifest.json`, `icon.svg`, `css`, `js`)
3. Netlify에서 내 프로젝트를 열고, "Already built it?" 영역(또는 Deploys 메뉴)에 **`배포용` 폴더를 통째로** 끌어다 놓습니다.
4. 폰에서 새로고침합니다. 예전 화면이 보이면 탭을 닫았다가 다시 엽니다.

내 PC에서만 시험할 때는 `run.bat`을 더블클릭하면 `http://localhost:5173/` 에서 열립니다.

## 4. 연결된 서비스와 설정 위치

| 서비스 | 용도 | 어디에 있나 |
|---|---|---|
| 구글 지도 | 지도, 장소 검색, 이동시간 | Google Cloud 콘솔의 API 키 (`config.js`의 `googleMapsKey`) |
| Firebase | 여행 데이터 저장·실시간 공유 | Firebase 콘솔의 Firestore (`config.js`의 `firebase`), 보안 규칙은 `firestore.rules` |
| Gemini | 영수증 사진 인식 | 키는 파일이 아니라 앱의 설정 탭에 입력. 여행 데이터에 저장되어 멤버가 함께 사용 |
| Netlify | 사이트 호스팅 | `배포용` 폴더를 올린 프로젝트 |
| 환율 | 하루 한 번 환율 수신 | open.er-api.com (키 불필요) |

실제 프로젝트 이름과 주소는 `개인메모.md`에 있습니다.

**구글 지도 키에 걸어 둔 제한**
- 허용 웹사이트: `http://localhost:5173/*`, 배포한 사이트 주소
- 허용 API: Maps JavaScript API, Places API (New), Routes API

사이트 주소를 바꾸면(Netlify의 Domain → Edit) 새 주소를 허용 웹사이트에 추가해야 지도가 뜹니다.

## 5. 비밀번호 잠금

`config.js`에는 지도 키와 Firebase 설정이 **비밀번호로 암호화된 상태**로 들어 있습니다. 비밀번호를 모르면 키가 풀리지 않아 지도·저장 기능을 쓸 수 없고, 폴더 어디에도 키가 평문으로 남아 있지 않습니다.

- 한 번 맞히면 그 기기(브라우저)에 기억됩니다. 홈 화면 앱은 따로 한 번 더 입력합니다.
- **비밀번호를 바꾸거나 잊었을 때**: 복구 방법이 없습니다. 구글 클라우드와 Firebase 콘솔에서 값을 다시 복사해 `config.js`를 아래 형태로 새로 채운 뒤, `http://localhost:5173/lock.html` 에서 새 비밀번호로 잠그고 `배포용`에 복사해 다시 올립니다.

```js
window.APP_CONFIG = {
  googleMapsKey: '지도 키',
  firebase: { apiKey: '', authDomain: '', projectId: '', storageBucket: '', messagingSenderId: '', appId: '' },
};
```

## 6. 요금

- **구글 지도**: 현재 무료 체험판이라 카드 청구가 없습니다. "업그레이드"를 누르지 않는 한 청구되지 않고, 크레딧이 다 떨어지거나 만료되면 지도 기능만 멈춥니다. 일정 목록·가계부·환율·사진은 계속 됩니다.
- 앱에서 지도를 쓰는 사람은 모두 내 지도 키 사용량으로 잡힙니다. 비밀번호 잠금과 웹사이트 제한으로 모르는 사람이 쓰는 것을 막아 두었습니다.
- 하루 사용량 한도는 걸지 못했습니다. 체험판 계정에서는 조정할 수 없는 것으로 표시됐습니다.
- **Firebase**: 무료 요금제. **Netlify**: 무료 요금제.

## 7. 알아둘 점과 아직 확인하지 못한 것

- **영수증 인식**: 실제 Gemini 키와 영수증으로 시험해 본 적이 없습니다. 처음 쓸 때 금액이 맞게 읽히는지 확인하세요.
- **일본 대중교통 시간**: 한 구간을 시험했을 때 도보 시간과 비슷하게 나왔습니다. 일본 일정은 구간 옆 "경로 ↗" 링크로 구글 지도에서 확인하는 편이 정확합니다.
- **환율**: 한국시간 오전 9시 이후 처음 열 때 한 번 받아와 다음 날 9시까지 같은 값을 씁니다. 시장 중간 환율이라 은행 고시 환율·실제 청구액과 조금 다를 수 있습니다.
- **카드 수수료**: 기본값은 해외결제 수수료 1.4% + 환율 가산 1%이며, 환율 탭에서 내 카드에 맞게 바꿉니다.
- **예약 여부·비용**: 구글이 정확히 주지 않는 정보라 직접 입력합니다. 구글이 "예약 가능"·가격대를 주는 장소만 자동으로 채워집니다.
- **사진**: 긴 변 1280px로 줄여 저장합니다. 원본 보관용이 아닙니다.
- **여행 삭제 기능은 없습니다.** 첫 화면의 ✕는 내 목록에서만 숨깁니다. 완전히 지우려면 Firebase 콘솔에서 삭제합니다.
- **여행북**: 사진 탭 → "여행북 만들기" → 인쇄 창에서 "PDF로 저장". 영상 내보내기는 없습니다.

## 8. 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 화면의 뼈대 |
| `config.js` | 암호화된 지도 키·Firebase 설정 (Git 제외) |
| `config.example.js` | `config.js`의 빈 양식 |
| `개인메모.md` | 내 사이트 주소·프로젝트 이름 (Git 제외) |
| `.gitignore` | Git에 올리지 않을 파일 목록 |
| `js/gate.js` | 비밀번호 화면과 설정 복호화 |
| `js/util.js` | 공통 도구, 통화 목록·검색·자동 추천 |
| `js/store.js` | 데이터 저장 (Firebase, 설정이 없으면 기기 저장) |
| `js/services.js` | 환율, 구글 지도, 영수증 인식 |
| `js/views.js` | 일정·가계부·환율·사진·설정 화면 |
| `js/app.js` | 첫 화면, 여행 열기, 탭 전환 |
| `css/style.css` | 디자인 |
| `lock.html` | 설정을 비밀번호로 잠그는 도구 (올릴 필요 없음) |
| `firestore.rules` | Firebase 보안 규칙 (콘솔에 붙여넣은 내용) |
| `run.bat`, `serve.ps1` | 내 PC에서 실행하기 |
| `배포용/` | Netlify에 올리는 폴더 (Git 제외) |

## 9. 만든 뒤 바뀐 내용 (2026-11-12)

처음 만든 버전에서 아래가 추가·수정됐습니다.

1. **Gemini 키 기억**: 한 번 저장하면 그 기기에 기억되어 새 여행에 자동으로 들어갑니다.
2. **통화 확대**: 통화 목록을 17개에서 환율이 제공되는 전체(약 166개)로 늘렸습니다.
3. **통화 자동 추천**: 여행 이름에 나라·도시가 들어 있으면 통화가 자동 선택됩니다. (예: "발리" → IDR)
4. **통화 검색**: 나라·도시·통화명·코드로 검색합니다. 새 여행 만들기, 설정, 환율 탭에 있습니다.
5. **통화 상단 고정**: 장소·지출 입력에서 여행지 통화와 원화(KRW)가 목록 맨 위에 고정됩니다.
6. **구글 지도 키 제한**: 허용 웹사이트와 허용 API 3개로 제한했습니다.
7. **비밀번호 잠금**: 지도 키·Firebase 설정을 비밀번호로 암호화했습니다.
8. **인터넷 배포**: `배포용` 폴더를 만들어 Netlify에 올렸습니다.
9. **폰 화면 수정**: 날짜·시간 칸이 옆 칸과 겹치던 문제를 고치고, 지출 입력의 환율을 소수 넷째 자리까지만 표시합니다.
10. **기존 여행 불러오기**: 첫 화면에서 초대 링크를 붙여넣어 여행을 엽니다.
11. **첫 화면 안내**: 설정 탭은 여행을 연 뒤에 나타난다는 안내를 넣었습니다.
